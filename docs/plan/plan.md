# Plan de estudio Ruta Senior

- Desarrollador backend con más de 7 años de experiencia. No empieza de cero: domina programación, APIs, SQL y Git.

- **Disponibilidad:** lunes, miércoles, viernes y sábado, 2 horas cada día (8 h por semana).
